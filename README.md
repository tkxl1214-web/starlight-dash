# 별빛 대시 ✦

작은 우주선을 움직여 별 조각을 모으고 운석을 피하는 브라우저 게임입니다. 설치나 외부 라이브러리 없이 바로 플레이할 수 있어요.

## 플레이

- 웹사이트: https://tkxl1214-web.github.io/starlight-dash/
- GitHub 저장소: https://github.com/tkxl1214-web/starlight-dash
- [게임 파일 ZIP 다운로드](https://github.com/tkxl1214-web/starlight-dash/archive/refs/heads/main.zip)

GitHub 저장소 페이지에서 **Code → Download ZIP**을 눌러도 게임 파일을 받을 수 있습니다.

## 조작법

- 키보드: ← → 또는 A / D
- 터치 화면: 게임 화면을 드래그하거나 아래 방향 버튼 사용
- P 또는 Esc: 일시정지
- 별 조각: 10점
- 운석: 보호막 감소

최고 기록은 현재 브라우저에 저장됩니다.

## 로컬에서 실행

`index.html` 파일을 브라우저에서 열면 됩니다.

## 배포

`main` 브랜치에 변경 사항을 올리면 GitHub Actions가 GitHub Pages에 자동 배포합니다.
